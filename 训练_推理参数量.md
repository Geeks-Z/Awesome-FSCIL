`Train` 表示单个 task 中真实参与训练的**新增参数量**（若分 task 不同，取最大值）；`Infer` 表示最终部署时相对 backbone 的**新增参数量**。单位均为 **M**。

### 参数量公式表

| Method      | Train Formula                                        | Infer Formula                                         |
| ----------- | ---------------------------------------------------- | ----------------------------------------------------- |
| L2P         | $D N_P (L_P + 1) + C(D + 1)$                         | $D N_P (L_P + 1) + C(D + 1)$                          |
| CODA-Prompt | $D N_L L (L_P + 2) + C(D + 1)$                       | $D N_L L (L_P + 2) + C(D + 1)$                        |
| LAE         | $4 D r L_A + C(D + 1)$                               | $4 D r L_A + C(D + 1)$                                |
| InfLoRA     | $2 D r L + C_0(D + 1)$                               | $4 D r L T + T C_0(D + 1)$                            |
| SD-LoRA     | $4 D r L + C(D + 1)$                                 | $4 D r L T + C(D + 1)$                                |
| ASP         | $D L_P L + f_\mu + f_\Sigma + (C D + 1)$             | $D L_P L + f_\mu + f_\Sigma + (C D + 1)$              |
| SEC-Prompt  | $D(L_P + 2)(N_D^{tr}L^D + N_{ND}L^{ND}) + (C D + 1)$ | $D(L_P + 2)(N_D^{inf}L^D + N_{ND}L^{ND}) + (C D + 1)$ |
| TALON-MLP   | $2 D r L$                                            | $2 D r$                                               |
| TALON-QV    | $4 D r L$                                            | $4 D r$                                               |
